# PiliPala UI Style Spec

## 定位

PiliPala 是轻量内容客户端，不做营销式视觉，也不复刻官方客户端的重装饰。界面应该让用户感觉快速、安静、清楚，内容本身是第一主角。

## 设计原则

1. 内容优先：视频封面、标题、作者、播放数据优先于装饰元素。
2. 低干扰：默认页面使用中性背景和轻分割，主题色只用于选中态、主操作、链接和状态。
3. 高密度但不拥挤：列表保持紧凑，正文可读，元信息用弱对比。
4. 原生 Material 3：保留系统动态取色和暗色模式，组件行为符合 Flutter/Material 预期。
5. 少嵌套卡片：页面区块不包大卡，卡片只用于重复内容项、入口、弹窗和真实工具面板。

## 颜色

默认品牌色使用低饱和绿色。动态取色开启时，系统色可覆盖品牌色，但页面仍遵守低干扰规则。

| Token | 用途 |
| --- | --- |
| `primary` | 选中态、主按钮、链接、认证文本 |
| `secondary` | 次级强调，不大面积使用 |
| `surface` | 页面主体背景 |
| `surfaceContainer` | 次级背景、列表区块背景 |
| `surfaceContainerHighest` | 入口按钮、筛选、轻面板 |
| `outlineVariant` | 分割线、弱描边 |
| `error` | 错误和危险操作 |

粉色只用于会员、特殊 badge、互动成功等强语义场景，不作为页面主色。

## 字体与信息层级

- 页面标题：`titleMedium`，加粗只用于当前页面或重要内容。
- 内容标题：`bodyLarge` 或 `titleSmall`，视频标题最多 2 行。
- 元信息：`labelMedium` / `bodySmall`，使用 `outline` 颜色。
- 不使用随屏幕宽度缩放的字号，依赖全局文本缩放设置。

## 间距与圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `safeSpace` | 12 | 页面左右安全边距、列表水平 padding |
| `itemSpace` | 8 | 列表项内部间距 |
| `sectionSpace` | 18 | 区块顶部间距 |
| `imgRadius` | 8 | 封面、头像外的图片圆角 |
| `mdRadius` | 8 | 小入口、按钮背景、轻面板 |
| `lgRadius` | 16 | 底部面板、弹窗、突出容器 |

## 核心组件规则

### 视频列表项

- 横向列表封面比例固定为 16:10。
- 左侧封面，右侧标题、作者、播放/弹幕/时间。
- 不为普通列表项添加外层卡片；使用页面背景和留白分组。
- 长按保留封面操作，点击进入视频详情。

### 区块标题

- 左侧标题，右侧可选“更多”文本按钮。
- 标题区只承担导航和层级，不承载说明性文案。

### 顶部导航

- 普通页面使用轻量 `AppBar`，不加重阴影。
- 内容详情页和空间页可使用沉浸式头图。
- 滚动后标题出现，避免一屏内重复大标题。

### Member 空间页

Member 页是第一阶段样板页，参考 `assets/screenshots/member.png` 的信息组织：

- 顶部封面图淡化铺底，向页面背景渐隐。
- 头像、关注/粉丝/动态统计和操作按钮位于同一个头部区域。
- 昵称、等级、会员、认证、签名按信息重要性排列。
- 下方提供动态、投稿、专栏等快速入口。
- 主页内容区显示合集、最近投币、最近喜欢的预览列表，并提供更多入口。
- 内容列表保持高密度，不使用大面积装饰卡。

## 暗色模式

- 保持动态取色，但降低渐变和大面积高饱和颜色。
- 列表背景与页面背景要有轻微层次，不使用纯黑。
- 图片和视频封面不加暗色蒙层，除非文字覆盖在图片上。

## 执行顺序

1. 建立全局 ThemeData 和 StyleString token。
2. 将 Member 页作为样板页打磨到位。
3. 抽取可复用的 section header 和视频列表项。
4. 逐步迁移首页、动态、媒体库、设置页。

## 验收标准

- `flutter analyze` 不新增 error。
- 样板页在浅色和暗色模式下文字不重叠、不溢出。
- 入口、按钮、列表项点击目标不小于 44px。
- 页面主色不超过三个语义区域：选中态、主按钮、链接/badge。
